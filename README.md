# All IN Market

ต้นแบบหน้าเว็บระบบจองล็อกตลาด All IN Market (23 หน้า: หน้าบ้าน + แอดมิน)
**ไม่มีข้อมูลสมมุติ** — เริ่มต้นว่างเปล่าทุกหน้า ข้อมูลจะปรากฏเมื่อมีการสมัคร / จอง / ชำระเงิน / ขอคืนล็อกจริงเท่านั้น

## วิธีเปิดดู
ต้องเปิดผ่านเซิร์ฟเวอร์ (ห้ามดับเบิลคลิกแบบ file://) และต้องต่ออินเทอร์เน็ต (โหลด React จาก CDN)

- Windows: ดับเบิลคลิก `start.bat` (เปิด http://localhost:8080)
- หรือ `php -S localhost:8080` / `python -m http.server 8080`
- หรือวางทั้งโฟลเดอร์ไว้ใน htdocs ของ XAMPP
- หรือ GitHub Pages

## ลำดับการใช้งาน
1. ผู้ใช้: สมัครสมาชิก (Register) → ยืนยัน OTP → เลือกล็อก (Booking) → บริการเสริม → แนบสลิป → ได้ใบจอง
2. แอดมิน: เข้า `AdminLogin.dc.html` → ตรวจสลิปที่หน้า "การจองและชำระเงิน" → อนุมัติ/ไม่ผ่าน
3. ผู้ใช้คืนล็อกได้ที่หน้า "คืนล็อก" → แอดมินอนุมัติคืนเงินที่หน้า "คำขอคืนล็อก"

บัญชีแอดมินเริ่มต้น: ชื่อผู้ใช้ `admin` / รหัสผ่าน `admin1234` (แก้ได้ที่ค่า `ADMIN` ในบนสุดของ `assets/js/store.js`)

## ข้อจำกัดของต้นแบบ (สำคัญ)
- ข้อมูลทั้งหมดเก็บใน **localStorage ของเบราว์เซอร์** ที่ใช้งาน: ผู้ใช้/การจอง ไม่แชร์ข้ามเครื่อง ไม่แชร์ระหว่างเพื่อนกับเรา
  (ถ้าต้องการใช้งานจริงหลายคน ต้องมีฐานข้อมูลฝั่งเซิร์ฟเวอร์)
- OTP ยังไม่ส่ง SMS จริง — รับรหัส 6 หลักใดก็ได้
- รหัสผ่านถูกแฮชแบบง่ายเพื่อการสาธิตเท่านั้น ไม่ใช่ระบบความปลอดภัยจริง
- ตลาดเปิดทุกวัน 15:00-00:00 · แอดมินทำงาน 09:00-23:00
- ราคา (แก้ได้ที่ `PRICES` ใน `assets/js/store.js`): ค่าเช่า 200 บาท/วัน · แพ็กเกจรายเดือน 5,000 บาท/เดือน · ล็อกขนาด 2×2 ม. · น้ำ 10 บาท/ล็อก/วัน · ไฟเหมาจ่าย 20 บาท/ล็อก/วัน · โต๊ะและเต็นท์ 100 บาท/วัน (บริการเสริมคิดต่อวันที่จอง)
- ยอดเงินคืนยังเป็น `[ยอดคืน]` เพราะยังไม่ได้กำหนดเงื่อนไขการคืนเงิน
- ล้างข้อมูลทั้งหมด: เปิด Console ของเบราว์เซอร์แล้วพิมพ์ `AIM.resetAll()` จากนั้นรีเฟรช

## โครงสร้าง
- `*.dc.html`  แต่ละหน้า (ชื่อต้องลงท้าย .dc.html เพราะลิงก์ภายในอ้างชื่อนี้)
- `assets/js/store.js`      ที่เก็บข้อมูลกลาง (ผู้ใช้ การจอง คำขอคืน ผังตลาด)
- `assets/js/pages/`        โค้ด JS ของแต่ละหน้า
- `assets/js/dc-runtime.js` runtime
- `assets/css/`             fonts.css + CSS ของแต่ละหน้า
- `assets/fonts`, `assets/images`
